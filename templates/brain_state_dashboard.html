About the project

This dashboard visualizes EEG brain-wave signals and estimates cognitive states such as focus, relaxation, and stress. It supports research on brain waves and frequencies and combines lightweight machine learning with clear visualizations to show how mental state changes over time. Data is loaded from the Emotiv Sample Data (EDF) dataset; choose subject and session below.
